# Single-Molecule Spectral Kymograph and Image Analysis

MATLAB pipeline for processing time-resolved microscopy TIFF stacks from a single-molecule spectroscopy setup. The script detects candidate emitters in the zeroth-order image, extracts their first-order emission spectra, constructs spectral kymographs, and produces per-emitter visualisations and summary data.

> **Research context:** Chowdhury Lab — Single-Molecule Spectroscopy, IIT Bombay. The pipeline is configured around a particular microscope geometry and wavelength calibration. Those values must be checked before applying it to a different instrument or dataset.

## What it does

The input frames contain two side-by-side regions generated by a transmission grating: a zeroth-order image used to locate emitters and a first-order region containing their spectra. The script runs the following workflow:

1. **Load the TIFF stack.** Reads each TIFF directory into a three-dimensional single-precision array, then calculates a time-averaged frame and a maximum-intensity projection (MIP).
2. **Define the spatial and spectral regions.** The zeroth-order search interval is controlled by `ZORDER_COL_MIN` and `ZORDER_COL_MAX`. The spectral region begins at `ZORDER_COL_MAX + ZORDER_GAP`.
3. **Detect emitters.** Builds a one-dimensional spatial profile from the MIP, calculates a robust threshold from the lower half of that profile, finds candidate peaks, and checks each candidate with a one-dimensional Gaussian shape test on a small image block. Nearby detections are reduced using a brighter-emitter rule.
4. **Extract spectra and kymographs.** Estimates a spectral centre and width from each emitter's average first-order spectrum, extracts the time-resolved wavelength window, and subtracts a column-wise percentile background. The wavelength axis uses the configured linear pixel-to-wavelength calibration.
5. **Characterise and export.** Generates per-emitter plots, estimates wavelength stability from per-frame intensity-weighted wavelength values, and fits a fixed three-Gaussian decomposition intended to represent the zero-phonon line (ZPL) and sideband components.

## Repository contents

- `spectral_kymograph.m` — main script and local helper functions. The supplied version includes `fit_gaussian1d` and `decompose_spectrum_kymograph`; no separate helper file is required for these functions.
- User-provided microscopy data are **not** included. Use data that you are authorised to analyse.

## Requirements

- MATLAB. **MATLAB R2022a or newer is recommended** because the script uses `prctile` as part of base MATLAB from R2022a onward. `exportgraphics` is used for figures (introduced in R2020a).
- The script attempts to use `findpeaks` when available. A fallback peak-selection routine is included if `findpeaks` fails, so the Signal Processing Toolbox is not strictly required for that step.
- Confirm that `lsqnonneg` is available in your MATLAB installation; the spectral-decomposition routine uses it for non-negative least-squares amplitudes and there is no fallback for that solver.
- Sufficient memory for the full stack to be held in memory. The movie array is stored in single precision, but the script also creates mean and maximum projections and per-particle arrays.

## How to run

1. Clone/download the repository and open MATLAB in the folder containing `spectral_kymograph.m`.
2. Open the script and edit `TIFF_PATH` to the full path of your multi-frame TIFF/OME-TIFF stack. The path in the supplied code is a machine-specific example and will not work on another computer.
3. Check the geometry, frame rate, wavelength calibration, and decomposition assumptions described below.
4. Run:

   ```matlab
   run('spectral_kymograph.m')
   ```

5. Results are written to a new folder next to the input file, named `<input-file-stem>_kymographs`.

## Parameters to review before each dataset

The default values in the script are examples for a particular acquisition and should not be treated as universal constants.

| Parameter | Purpose | Supplied default |
|---|---|---:|
| `TIFF_PATH` | Full path to input TIFF stack | Machine-specific path; replace it |
| `ZORDER_COL_MIN`, `ZORDER_COL_MAX` | Inclusive zeroth-order search columns | `13`, `64` |
| `ZORDER_GAP` | Gap between zeroth-order range and first-order region | `15` (set in the script) |
| `THRESHOLD` | Threshold multiplier for the profile background standard deviation | `8` |
| `MIN_SEPARATION` | Minimum separation for peak selection, in rows/pixels | `5` |
| `HALF_WIDTH`, `VERTICAL_ALLOWANCE` | Half-width and extra allowance for the spectral extraction row band | `2`, `2` |
| `FRAME_RATE` | Acquisition rate used to label the time axis | `20` Hz |
| `BG_PERCENTILE` | Percentile used for column-wise kymograph background subtraction | `5` |
| `STATIC_THRESHOLD_NM` | Wavelength-standard-deviation cutoff used for the static/diffusing label | `5.0` nm |
| `MAX_PARTICLES` | Optional cap; empty means process all accepted particles | `[]` |
| `SAVE_MAT` | Whether to save the core kymograph arrays and parameters | `true` |

The supplied pixel-to-wavelength map is `lambda_nm = 1.2 * pixel_index - 40`, where `pixel_index` is local to the extracted first-order spectral region. **Replace/validate this calibration for the instrument and dataset you are analysing.** The decomposition also assumes fixed component offsets `[0, -5.8, -11.6]` nm and fixed widths `[4, 5, 6]` nm; these are model assumptions embedded in `decompose_spectrum_kymograph` and must be reviewed before interpreting the fitted components physically.

## Output files

The output directory contains the following (subject to successful completion and the number of detected particles):

- `00_detection_overview.png` — mean-frame image with the search region and accepted detections, plus the MIP-derived spatial profile and threshold.
- `particle_NNN_kymograph.png` — raw and background-subtracted kymographs, average spectrum/Gaussian estimate, and integrated photoluminescence (PL) intensity trace; title includes the location and stability label.
- `particle_NNN_decomposition_trajectories.png` — fitted ZPL-centre trajectory and the amplitude-ratio/Huang–Rhys proxy over time.
- `particle_NNN_decomposition_amplitudes.png` — fitted component amplitudes over time.
- `particle_NNN_decomposition_spectrum.png` — example mean-on spectrum with fitted Gaussian components.
- `00_all_kymographs_mosaic.png` — mosaic of background-subtracted kymographs.
- `00_particle_summary.txt` — tab-delimited per-particle coordinates, mean wavelength (when classified static), wavelength standard deviation, and stability label.
- `kymographs.mat` — saved when `SAVE_MAT = true`; contains raw/corrected kymographs, wavelength axes, particle coordinates/profile values, Gaussian parameters, and acquisition/geometry parameters.
- `particle_NNN_decomposition.mat` — per-particle decomposition fit outputs.

## Interpretation notes and limitations

- Emitter detection uses a maximum-intensity projection so blinking emitters can be detected at their peak brightness. Downstream spectrum/kymograph extraction uses the time-averaged frame and individual frames as implemented in the script.
- The Gaussian helper estimates amplitude, centre and width using weighted moments; it is not a general nonlinear fit to an arbitrary measured line shape.
- The component count, offsets and widths used for decomposition are fixed in the code. The returned `HR_factor` is explicitly a proxy `A2/A1`; don't treat it as a validated material constant without checking the model and underlying assumptions.
- The static/diffusing label is assigned using the standard deviation of an intensity-weighted wavelength estimate on frames selected as on-frames. It is a heuristic based on `STATIC_THRESHOLD_NM`, not a universal classification criterion.
- The script does not currently parse instrument wavelength calibration or frame rate from OME metadata; these are supplied by the user/code configuration.
- No sample data or ground-truth labels are supplied, so the repository alone does not establish accuracy, detection sensitivity, or generalisation to other microscopes/datasets.

## Reproducibility checklist

Before analysing a new stack, record the input filename, MATLAB release, acquisition rate, zeroth-order bounds, gap, threshold, pixel-to-wavelength calibration, background percentile, static threshold, and decomposition offsets/widths. Inspect the detection overview and representative kymographs before drawing physical conclusions.
